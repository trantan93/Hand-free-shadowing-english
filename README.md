# Luyện nói tiếng Anh – Shadowing

Ứng dụng web tĩnh luyện shadowing tiếng Anh không cần chạm tay: bot đọc câu hai lần (speechSynthesis), ghi âm và tự dừng khi im lặng, phát lại bản ghi, rồi chọn **Đọc lại** hoặc **Câu tiếp**.

Trang web: https://trantan93.github.io/Hand-free-shadowing-english/ (sau khi bật GitHub Pages từ nhánh `main`, thư mục `/`).

Tệp: `index.html` (toàn bộ app, CSS/JS nhúng), `manifest.webmanifest`, icon, `ipa-dict.json` (IPA tiếng Anh Mỹ offline, khoảng 18 nghìn từ, từ CMUdict). Không cần backend.
